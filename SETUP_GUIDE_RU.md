# CarCare Log: как установить приложение на свой iPhone

Инструкция для человека без технической подготовки. Всё делается с компьютера на Windows и с iPhone.
Mac не нужен.

Идите по шагам сверху вниз. После каждого шага есть пункт **«Что вы должны увидеть»**. Если видите что-то
другое, остановитесь и напишите разработчику (или Claude), что именно видно на экране.

---

## Что понадобится

- iPhone с iOS 17 или новее (Настройки → Основные → Об этом устройстве → «Версия iOS»).
- Ваш Apple ID (тот, с которым вы входите в App Store) с включённой двухфакторной защитой.
- Банковская карта: программа разработчика Apple стоит **99 $ в год**. Больше платить не придётся.
- Компьютер с Windows и браузером.

## Сколько это стоит

| Что | Цена |
|---|---|
| Apple Developer Program | 99 $ в год (обязательно, без этого приложение на iPhone не поставить) |
| GitHub (хранение кода и сборка) | бесплатно |
| Сборка приложения в облаке (GitHub Actions) | бесплатно: для открытого репозитория минуты не ограничены |
| Codemagic (запасной вариант, обычно не нужен) | бесплатно до 500 минут в месяц |

## Шаг 1. Apple Developer Program. Начните с него: проверка длится до нескольких дней

1. На iPhone установите из App Store приложение **Apple Developer** (значок с синим молотком).
2. Откройте его → вкладка **Account** → войдите со своим Apple ID.
3. Нажмите **Enroll Now** (Записаться) → выберите **Individual** (физическое лицо) → заполните имя и адрес
   **латиницей**, как в паспорте → оплатите 99 $.

Если удобнее с компьютера: откройте https://developer.apple.com/programs/enroll/ → **Start your enrollment**.

**Что вы должны увидеть:** письмо от Apple «Welcome to the Apple Developer Program». Обычно оно приходит в течение
1–2 дней, иногда позже. Пока письма нет, шаги 4–10 сделать не получится. Это нормально, просто подождите.

---

## Шаг 2. GitHub. Уже сделано

Аккаунт GitHub **pe4eniye** уже создан, код лежит здесь: https://github.com/pe4eniye/CarCareLog

**Что вы должны увидеть:** открыв ссылку, вы видите список файлов (`App`, `Packages`, `README_DEV.md` и другие).

---

## Шаг 3. Облачная сборка. Тоже уже готово

Приложение собирается на серверах GitHub (сервис «GitHub Actions»). Для открытого репозитория это бесплатно и без
ограничений. Отдельный аккаунт на Codemagic **не нужен**. Он описан в файле `codemagic.yaml` только как запасной вариант.

**Что вы должны увидеть:** на странице репозитория откройте вкладку **Actions**. Там есть строки «CI» с зелёными
галочками ✅.

---

## Шаг 4. Узнать свой Team ID (после письма из шага 1)

1. Откройте https://developer.apple.com/account и войдите со своим Apple ID.
2. Прокрутите до блока **Membership details** (Сведения об участии).
3. Найдите строку **Team ID**. Это 10 латинских букв и цифр, например `A1B2C3D4E5`. Скопируйте её в Блокнот.

**Что вы должны увидеть:** строку «Team ID» с кодом из 10 символов.

---

## Шаг 5. Создать ключ App Store Connect API

Этот ключ позволяет серверу GitHub подписывать приложение и отправлять его в TestFlight от вашего имени.

1. Откройте https://appstoreconnect.apple.com и войдите.
2. Нажмите **Users and Access** (Пользователи и доступ) → вверху вкладка **Integrations** (Интеграции) →
   слева **App Store Connect API**.
3. Если вы здесь впервые, нажмите **Request Access** (Запросить доступ), согласитесь с условиями и подождите,
   пока появится кнопка создания ключа.
4. Вкладка **Team Keys** → кнопка **+** (Generate API Key).
5. Name (название): `CarCare CI`. Access (доступ): **Admin**. Нажмите **Generate**.
6. В строке нового ключа нажмите **Download API Key** (Скачать). **Скачать можно только один раз!** Файл называется
   `AuthKey_XXXXXXXXXX.p8`. Сохраните его в надёжное место.
7. На этой же странице скопируйте в Блокнот:
   - **Key ID**: код в строке ключа (10 символов);
   - **Issuer ID**: длинный код с дефисами над таблицей ключей.

**Что вы должны увидеть:** в списке ключей есть строка «CarCare CI» с доступом «Admin», а в папке «Загрузки»
лежит файл `AuthKey_….p8`.

> Никому не пересылайте этот файл и не публикуйте его. Если он потерялся или попал к чужим людям, нажмите на
> этой странице **Revoke** (Отозвать) и создайте новый ключ.

---

## Шаг 6. Положить секреты в GitHub

1. Откройте https://github.com/pe4eniye/CarCareLog/settings/secrets/actions
2. Нажмите **New repository secret** и создайте по очереди **четыре** секрета:

| Name (точно так) | Secret (что вставить) |
|---|---|
| `APPLE_TEAM_ID` | Team ID из шага 4 |
| `ASC_KEY_ID` | Key ID из шага 5 |
| `ASC_ISSUER_ID` | Issuer ID из шага 5 |
| `ASC_KEY_P8` | Всё содержимое файла `.p8`: правый клик по файлу → «Открыть с помощью» → «Блокнот» → Ctrl+A → Ctrl+C → вставить |

После каждого нажимайте **Add secret**.

**Что вы должны увидеть:** в списке «Repository secrets» четыре строки: `APPLE_TEAM_ID`, `ASC_ISSUER_ID`,
`ASC_KEY_ID`, `ASC_KEY_P8`. Значения GitHub не показывает, так и должно быть.

---

## Шаг 7. Зарегистрировать идентификатор приложения (Bundle ID)

1. Откройте https://developer.apple.com/account/resources/identifiers/list
2. Нажмите синий **+** рядом с «Identifiers».
3. Выберите **App IDs** → **Continue** → выберите **App** → **Continue**.
4. Description: `CarCare Log`. Bundle ID: выберите **Explicit** и впишите точно: `com.carcarelog.app`
5. Ниже в списке Capabilities поставьте галочку **App Groups**.
6. **Continue** → **Register**.

**Что вы должны увидеть:** в списке Identifiers есть строка «CarCare Log — com.carcarelog.app».

> Если Apple пишет, что `com.carcarelog.app` уже занят кем-то другим, напишите разработчику: нужно будет выбрать
> другой идентификатор (например, `com.ВАШЕИМЯ.carcarelog`) и поменять его в файле `project.yml`.

---

## Шаг 8. Создать карточку приложения в App Store Connect

1. Откройте https://appstoreconnect.apple.com → **Apps** (Приложения) → синий **+** → **New App** (Новое приложение).
2. Заполните:
   - Platforms: **iOS**
   - Name: `CarCare Log` (если имя занято, добавьте что-нибудь, например `CarCare Log UA`; это только название в магазине)
   - Primary Language: **Ukrainian**
   - Bundle ID: выберите `CarCare Log - com.carcarelog.app`
   - SKU: `carcarelog001`
   - User Access: **Full Access**
3. Нажмите **Create** (Создать).

**Что вы должны увидеть:** страницу приложения «CarCare Log» с вкладками «Distribution», «TestFlight» и другими.

---

## Шаг 9. Собрать приложение и отправить в TestFlight

1. Откройте https://github.com/pe4eniye/CarCareLog/actions
2. Слева выберите **Release to TestFlight**.
3. Справа нажмите **Run workflow** → снова зелёную кнопку **Run workflow**. Галочку «icloud» **не ставьте**.
4. Подождите 10–20 минут, страницу можно закрыть.

**Что вы должны увидеть:** строка запуска сначала с жёлтым кружком, потом с **зелёной галочкой ✅**. Внутри запуска
внизу написано «Build … uploaded to TestFlight ✅». Через 5–30 минут на почту придёт письмо от Apple, что сборка
обработана («has completed processing»).

Если вместо галочки **красный крестик ❌**, откройте запуск, нажмите на шаг с крестиком, скопируйте последние
строки и отправьте разработчику. Частые причины:
- «Missing secrets»: в шаге 6 пропущен секрет или в названии опечатка;
- «No suitable application records were found»: не сделан шаг 8;
- ошибка про «agreement»: в App Store Connect нужно принять новое соглашение Apple (баннер вверху сайта).

---

## Шаг 10. Установить приложение на iPhone через TestFlight

1. В App Store Connect откройте приложение → вкладка **TestFlight**.
2. Слева в разделе **Internal Testing** нажмите **+** → название группы `Я` → **Create**.
3. В группе: **Testers** → **+** → отметьте себя → **Add**. Затем **Builds** → **+** → выберите сборку → **Add**.
4. На iPhone установите из App Store приложение **TestFlight** (синий пропеллер).
5. Откройте письмо-приглашение от TestFlight на iPhone → **View in TestFlight** → **Accept** → **Install**.

**Что вы должны увидеть:** на экране iPhone появился значок CarCare Log (синий спидометр). При первом запуске
приложение попросит данные об авто: марку, модель и текущий пробег.

---

## Шаг 11. Как обновлять приложение

Когда разработчик сообщит, что есть новая версия:
1. Повторите шаг 9 (Actions → Release to TestFlight → Run workflow).
2. Через 10–30 минут откройте на iPhone приложение **TestFlight** → CarCare Log → **Update** (Обновить).

**Что вы должны увидеть:** в TestFlight у CarCare Log новый номер сборки, а ваши данные в приложении на месте.

---

## Шаг 12. Каждые 80 дней перевыпускать сборку. Это важно!

Сборки из TestFlight **перестают открываться через 90 дней**. Чтобы этого не случилось, **раз в 2 месяца**
повторяйте шаг 9 и обновляйтесь в TestFlight (шаг 11), даже если в коде ничего не менялось.

Совет: поставьте себе повторяющееся напоминание в календаре на телефоне: «CarCare: перевыпустить сборку», раз в 2 месяца.

**Что вы должны увидеть:** в приложении TestFlight у CarCare Log написано «Expires in 89 days» или около того.

> На всякий случай перед каждым обновлением делайте резервную копию (шаг 13).

---

## Шаг 13. Резервная копия: сохранить и восстановить

**Сохранить:**
1. CarCare Log → **Налаштування** (Настройки) → **Експортувати резервну копію**.
2. Выберите **Сохранить в «Файлы»** → папка «iCloud Drive» или «На iPhone» → **Сохранить**.
   Можно отправить файл себе по почте или через AirDrop на другой телефон.

**Что вы должны увидеть:** в приложении «Файлы» есть файл вида `CarCareLog-backup-2026-10-07.json`.

**Восстановить** (новый телефон, переустановка, ошибка):
1. Установите приложение (шаг 10) и пройдите начальную настройку.
2. **Налаштування** → **Імпортувати резервну копію** → выберите файл `CarCareLog-backup-….json`.
3. Приложение спросит «Замінити дані?» и покажет дату файла и количество записей. Нажмите **Замінити**.

**Что вы должны увидеть:** сообщение «Дані відновлено», история и запчасти на месте.

## Запасной путь: Mac друга с Xcode

Если облачная сборка по какой-то причине не работает:
1. На Mac установите **Xcode** из Mac App Store (бесплатно, около 10 ГБ).
2. В «Терминале» выполните по очереди:
   ```
   brew install xcodegen
   git clone https://github.com/pe4eniye/CarCareLog.git
   cd CarCareLog
   xcodegen generate
   open CarCareLog.xcodeproj
   ```
   (если команда `brew` не найдена, сначала установите Homebrew с сайта https://brew.sh)
3. В Xcode: **Settings → Accounts** → «+» → войдите со своим Apple ID.
4. Слева выберите проект **CarCareLog** → цель **CarCareLog** → вкладка **Signing & Capabilities** → **Team**: выберите
   свою команду. То же самое для цели **CarCareWidget**.
5. Меню **Product → Archive** → в открывшемся окне **Distribute App** → **TestFlight & App Store** → **Distribute**.
6. Дальше как в шаге 10.

**Что вы должны увидеть:** в Xcode надпись «Upload Successful», через 5–30 минут сборка появится в TestFlight.

## Необязательно: резервная копия в iCloud (нужен Mac один раз)

Приложение полностью работает и без iCloud. Файл из шага 13 — надёжная резервная копия. Если хочется
автоматической синхронизации через iCloud, нужно один раз выполнить на Mac (например, у друга):
1. В https://developer.apple.com/account/resources/identifiers/list нажмите «+» → **iCloud Containers** →
   идентификатор `iCloud.com.carcarelog.app` → Register. Затем откройте App ID `com.carcarelog.app` → включите
   **iCloud** (CloudKit) → **Edit** → отметьте этот контейнер → Save.
2. На Mac (как в «Запасном пути») в Xcode: цель CarCareLog → Build Settings → найдите `CC_ICLOUD` → поставьте `YES`.
   Product → Scheme → Edit Scheme → Run → Arguments → добавьте `-initCloudKitSchema`. Подключите iPhone кабелем и
   нажмите ▶︎ (Run).
3. Откройте https://icloud.developer.apple.com → CloudKit Database → контейнер `iCloud.com.carcarelog.app` →
   **Deploy Schema Changes** → Deploy.
4. После этого запускайте шаг 9 **с галочкой «icloud»**.

**Что вы должны увидеть:** в приложении в «Налаштування» строка iCloud показывает «Увімкнено».

## Позже: публикация в App Store (кратко)

1. В App Store Connect на странице приложения заполните: описание, ключевые слова, 3+ скриншота iPhone 6,9″
   (их можно снять на своём iPhone), ссылку на политику конфиденциальности (можно страницу на GitHub с текстом
   «Приложение не собирает данные»), категорию «Утилиты» или «Образ жизни».
2. Раздел **App Privacy**: «Data Not Collected» (приложение ничего не собирает).
3. Выберите сборку из TestFlight → **Add for Review** → **Submit**.
4. Проверка Apple обычно занимает 1–3 дня. Публикация в App Store не требует перевыпуска каждые 90 дней.
